# MIDI Captain MAX Documentation

User guides for **MIDI Captain MAX (MCM)** — open-source firmware and a desktop config editor for the PaintAudio MIDI Captain.

## Guides

- [Inbound MIDI](./inbound-midi.md) — host-to-device button sync: state mode and select mode
- [Page Control (MIDI-IN)](./page-control.md) — let an inbound CC jump or step through pages
- [MIDI Thru Matrix](./midi-thru.md) — routing MIDI between USB and 5-pin DIN

More guides are on the way. For developer documentation, see the [`docs/`](https://github.com/MC-Music-Workshop/midi-captain-max/tree/main/docs) folder in the repo.
